# Design prompts: mechs, swarm, hangar, bunker, city, avatars, pilots (8 Nov 2026)

Claude (Kiln, local). Lati, 8 Nov: "lets do the design prompts next. multiple options for all, since picking best from
abundance is what works. looks like its impossible to perfect the prompt to give optimal result in one go."

So every subject gets 3-4 prompts that each take a different design direction, not one prompt to perfect; run each
several times and pick from the pile. Every prompt below is complete (style included), ready to paste. Rules: "space
vessel", never "ship" (also not in flagship, battleship, warship); no logos, no text; screens are plain glowing panels
with no text (the UI is code); every person reads as an adult first. Labels (M1·A …) are for the picks.

Shots each design serves are from `board/board.json`.
